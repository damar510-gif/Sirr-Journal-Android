# سِرّ — تثبيت المذكرة على أندرويد

هذا المستودع يحتوي صفحة التثبيت العامة فقط. لا يحتوي مذكرات أو كلمة مرور أو ملفات خادم Apps Script. يدخل كل مستخدم رابط نشر مذكرته من إعدادات التطبيق.

## نشر الصفحة

في Settings → Pages اختر **Deploy from a branch**، ثم **main** والمجلد **/ (root)** واضغط Save. لا تحتاج إضافة أسرار أو إعداد سير عمل خاص.

بعد نجاح بناء Pages سيكون رابط التثبيت:
https://damar510-gif.github.io/Sirr-Journal-Android/

افتح الصفحة في Chrome على أندرويد، واختر «إعداد المذكرة»، وأدخل رابط نشر Apps Script الذي ينتهي بـ /exec. اختر اسم التطبيق وأيقونته ثم «حفظ وفتح المذكرة». اضغط «تثبيت التطبيق» أو استخدم قائمة Chrome ← تثبيت التطبيق / إضافة إلى الشاشة الرئيسية.

الحفظ وفتح المذكرات يحتاجان إلى الإنترنت. يحتاج نشر Apps Script إلى السماح بالتضمين والتنفيذ باسم المالك والوصول «أي شخص» ليعمل بالرابط وكلمة المرور.

## الملفات

ملفات التشغيل التسعة في جذر المستودع. يحتفظ العامل الخدمي بملفات صفحة التثبيت فقط؛ لا يخزن كلمات المرور أو محتوى المذكرات. عند تحديث ملفات الواجهة، حدّث رقم CACHE في sw.js لتحديث النسخة المتاحة دون اتصال.
