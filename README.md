# سِرّ — تثبيت المذكرة على أندرويد

هذا المستودع يحتوي صفحة التثبيت العامة فقط. لا يحتوي مذكرات أو كلمة مرور أو ملفات خادم Apps Script. يدخل كل مستخدم رابط نشر مذكرته من إعدادات التطبيق.

## نشر الصفحة

في Settings → Pages اختر **Deploy from a branch**، ثم **main** والمجلد **/ (root)** واضغط Save. لا تحتاج إضافة أسرار أو إعداد سير عمل خاص.

بعد نجاح بناء Pages سيكون رابط التثبيت:
https://damar510-gif.github.io/Sirr-Journal-Android/

افتح الصفحة في Chrome على أندرويد، واختر «إعداد المذكرة»، وأدخل رابط نشر Apps Script الذي ينتهي بـ /exec. اختر اسم التطبيق وأيقونته ثم «حفظ وفتح المذكرة». اضغط «تثبيت التطبيق» أو استخدم قائمة Chrome ← تثبيت التطبيق / إضافة إلى الشاشة الرئيسية.

الحفظ وفتح المذكرات يحتاجان إلى الإنترنت. يحتاج نشر Apps Script إلى السماح بالتضمين والتنفيذ باسم المالك والوصول «أي شخص» ليعمل بالرابط وكلمة المرور.

## مساحة التطبيق والمظهر في 1.3.0

بعد جاهزية المذكرة يختفي الشريط الأبيض الذي يحمل الشعار والإعدادات، وتملأ المذكرة مساحة نافذة التطبيق. تفتح إعدادات الربط والاسم والأيقونة من زر **إعدادات تطبيق أندرويد** في شاشة الدخول أو إعدادات المذكرة. عند استخدام واجهة مذكرة قديمة يبقى زر ترس صغير عائم لفتح هذه الإعدادات حتى تحديث `Index.html`.

لتحديث التطبيق المثبّت، احفظ كتاباتك ثم أغلقه وافتحه مع اتصال الإنترنت ليحمّل تحديث صفحة التثبيت. لا تحتاج إزالة التطبيق أو إعادة تثبيته لهذا التحديث.

داخل المذكرة اختر **الإعدادات ← شكل مساحتك** لتجد القوالب الإضافية: **منتصف الليل**، **أسود خالص**، **ليل البنفسج**، و**قهوة المساء**. زر المظهر يعيد آخر قالب داكن اخترته بعد الانتقال إلى الفاتح؛ يُحفظ الاختيار مشفّرًا مع الدفتر.

إن كانت المذكرة على 1.2.1، يكفي أن يحدّث مالكها محتوى `Index.html` في مشروع Apps Script الحالي ثم **نشر ← إدارة عمليات النشر ← تعديل ← إصدار جديد ← نشر** لتظهر القوالب وزر الإعدادات الداخلي. تحديث `Code.gs` اختياري لمطابقة رقم الإصدار، دون تغيير في واجهة الخادم؛ `appsscript.json` والصلاحيات لا تتغير ولا تحتاج إعادة تشغيل `setup_`.

## الملفات

ملفات التشغيل التسعة في جذر المستودع. يحتفظ العامل الخدمي بملفات صفحة التثبيت فقط؛ لا يخزن كلمات المرور أو محتوى المذكرات. عند تحديث ملفات الواجهة، حدّث رقم CACHE في sw.js لتحديث النسخة المتاحة دون اتصال.
